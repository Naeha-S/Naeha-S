🧠 Spot the bug
<details> <summary><b>Round 1 — JavaScript</b> · <i>which line breaks it?</i></summary> <br/>
js
const loadRoutes = async () => {
  const res = await fetch("/api/buses");
  const data = res.json();
  return data.routes.map((r) => r.id);
};
Answer: res.json() is missing await. It returns a Promise, so data.routes is undefined and .map throws TypeError. Needs await res.json().

</details><details> <summary><b>Round 2 — JavaScript</b> · <i>what does this print?</i></summary> <br/>
js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i));
Answer: 3 3 3. var is function-scoped, so all three callbacks close over the same binding after the loop finished. let gives 0 1 2.

</details><details> <summary><b>Round 3 — CSS</b> · <i>why doesn't the card centre?</i></summary> <br/>
css
.card { position: absolute; left: 50%; top: 50%; }
Answer: the element's own box isn't offset, so its top-left corner sits at the centre rather than the element. Either transform: translate(-50%, -50%) or, better, put display: grid; place-items: center on the parent.

</details><br/>
