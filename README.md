## 🧩 play with me

<div align="center">

<table>
<tr>

<td align="center" valign="top" width="33%">

**🧠 spot the bug**

<details>
<summary>Round 1 · JS · <i>which line?</i></summary>
<br/>

```js
const loadRoutes = async () => {
  const res = await fetch("/api/buses");
  const data = res.json();          // 👀
  return data.routes.map(r => r.id);
};
```
<sub><b>Answer:</b> <code>res.json()</code> needs <code>await</code>. Returns a Promise → <code>data.routes</code> is undefined → TypeError.</sub>
</details>

<details>
<summary>Round 2 · JS · <i>what prints?</i></summary>
<br/>

```js
for (var i = 0; i < 3; i++)
  setTimeout(() => console.log(i));
```
<sub><b>Answer:</b> <code>3 3 3</code> — <code>var</code> is function-scoped. Use <code>let</code> for <code>0 1 2</code>.</sub>
</details>

<details>
<summary>Round 3 · CSS · <i>why won't it centre?</i></summary>
<br/>

```css
.card { position: absolute;
        left: 50%; top: 50%; }
```
<sub><b>Answer:</b> offsets the top-left corner, not the element. Add <code>transform: translate(-50%,-50%)</code> or use <code>grid + place-items:center</code> on the parent.</sub>
</details>
